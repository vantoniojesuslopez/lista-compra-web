# Lista Compra · web

Página pública de la app **Lista Compra** (Android), publicada con GitHub Pages:
https://vantoniojesuslopez.github.io/lista-compra-web/

- `privacidad.html`: política de privacidad (enlazada desde la app y desde Google Play).
- `servidores.json`: servidores de OpenStreetMap que usa «Cerca de ti». La app lo lee al abrirse, así que
  cambiarlo aquí cambia los servidores en todos los móviles sin sacar una versión nueva.
  `"cerca_de_ti": false` apaga la función y enseña el texto de `"aviso"`.

El contenido se mantiene en el repositorio de la app (carpeta `pagina-web/`) y se copia aquí.
